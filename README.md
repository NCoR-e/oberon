<h1>Oberon by HVR Group</h1>
<h2>От идеи формирования макета с 0 до реализации ВЕБ-SPA <br>(через параллельное обучение участников группы разработки)</h2>

<h3>Данный проект представляет собой продукт интеллектуальной собственности (HVR Group) через параллельное обучение для членов группы HVR, поэтому он может быть дополнительно усовершенствован, внедрены новые технологии, а также проведена масштабная рефакторизация и замена используемых технологий по мере возникновения проблем или идей по улучшению.</h3>
